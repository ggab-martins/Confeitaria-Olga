
# Confeitaria Olga

Sistema de gestão de confeitaria com módulos de:
- Produção
- Estoque
- Fichas técnicas
- Escalas de trabalho
- Relatórios
- Dashboard

## Como publicar na internet

1. Crie uma conta gratuita em https://vercel.com
2. Clique em **Add New Project**
3. Envie esta pasta
4. O sistema ficará online com um link como:

   https://confeitaria-olga.vercel.app

## Instalar no celular

Abra o site no navegador e clique em:

**Adicionar à tela inicial**

Ele funcionará como um aplicativo.
